# Umar Abdulaziz Bashir - Professional Portfolio

A clean and professional portfolio website showcasing my work as an AI & Machine Learning Engineer and Backend Developer.

## 🌐 Live Portfolio

The portfolio can be accessed by opening `index.html` in any modern web browser.

## 📂 Files

- `index.html` - Main portfolio page with all sections
- `style.css` - Complete styling with responsive design
- `script.js` - Interactive features and animations

## ✨ Features

### Design
- Modern dark theme with gradient accents (blue to purple)
- Clean, professional layout
- Smooth animations and transitions
- Fully responsive for mobile and desktop

### Sections
1. **Hero Section** - Introduction with call-to-action buttons
2. **About** - Professional background and education
3. **Experience** - Timeline of professional roles
4. **Projects** - Showcase of 4 featured projects
5. **Skills** - Technical skills organized by category
6. **Contact** - Multiple ways to get in touch

### Interactive Elements
- Smooth scrolling navigation
- Mobile-friendly hamburger menu
- Hover effects and transitions
- Active section highlighting
- Social media links (Email, LinkedIn, GitHub)

## 🚀 Viewing the Portfolio

### Local Viewing
Simply open `index.html` in your web browser:
```bash
# Using Python
python3 -m http.server 8000
# Then visit: http://localhost:8000

# Or just double-click index.html
```

### Deployment Options

#### GitHub Pages
1. Go to repository Settings → Pages
2. Select the branch (`copilot/create-umar-portfolio` or `main`)
3. Select root directory
4. Click Save
5. Your portfolio will be live at your GitHub Pages URL

#### Netlify
1. Drag and drop the three files (`index.html`, `style.css`, `script.js`) to Netlify
2. Or connect your GitHub repository
3. Deploy automatically

#### Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project directory
3. Follow the prompts

## 🛠️ Customization

To customize the portfolio:

1. **Colors**: Edit CSS variables in `style.css` (lines 7-18)
2. **Content**: Modify text directly in `index.html`
3. **Projects**: Update project cards in the Projects section
4. **Links**: Change social media and project URLs as needed
